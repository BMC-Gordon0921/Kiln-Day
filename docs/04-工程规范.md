# 04 · 工程规范

短，但都是会疼的地方。

## 1. 命名与文件

- 目录、文件名：`snake_case`（Godot 官方风格）。类名 `PascalCase` 并用 `class_name` 暴露。
- 私有成员 `_leading_underscore`；常量 `UPPER_SNAKE`；信号 `snake_case` 的过去式（`save_loaded`）。
- 一个文件一个 `class_name`。纯静态工具用 `extends RefCounted` + `static func`（如 `Catalog`、`AssetManifest`）。
- `autoload/` 里的脚本**不要**加 `class_name` —— 会与自动加载单例同名冲突。
- 缩进用 Tab（Godot 默认），`.gd` 文件 UTF-8 无 BOM。

## 2. 分层与依赖方向

```
scenes/ (节点，可有 @export)
   ↓
autoload/ (Events 信号总线、GameState 运行时状态、SaveGame 存档、Settings 配置)
   ↓
core/ 与 data/defs/ (纯逻辑，不 import 任何场景，不拿 Node)
```

规则：

- **`core/` 里禁止出现 `get_node` / `preload` 场景 / `Input` / `OS.get_ticks_msec`**。
  需要时间和输入的地方，从调用方传进来（`order_income(base, {elapsed_ms = ...})` 这种形状）。
  这是 `core/` 能被无头测试的直接原因。
- 跨模块通信走 `Events` 信号，不要互相 `get_node("../OtherModule")`。
- 平台差异只允许出现在 `ContentPack`（`OS.has_feature("demo")`）和 `Settings`，别散落。

## 3. 测试

- 用例放 `game/tests/cases/test_*.gd`，`extends RefCounted`，实现 `run(report: TestReport)`。
- 新用例要在 `game/tests/run_tests.gd` 的 `SUITES` 数组里登记，否则不会跑。
- 只测**纯逻辑**。要场景树的测试放 `tests/integration/`，另开入口，别混进无头入口。
- 断言用 `report.eq(actual, expected, "说明")` / `report.ok(cond, "说明")`，说明写清楚"期望什么"。
- 测试必须离线可跑、无随机、无等待。涉及随机的逻辑（窑变、抽卡）要把种子当参数传进来。

## 4. 日志标记

无头脚本靠 ASCII 标记判断成败，因为中文在 Windows 控制台下不可靠：

| 标记 | 用途 |
| --- | --- |
| `BOOT_OK` / `BOOT_FAIL` | 启动自检结果 |
| `ASSETLAB_OK` | glTF 实例化成功 |
| `ALL TESTS PASSED` / `TESTS FAILED: N` | 测试结果 |

新增「机器要判断的输出」时，按同样风格加 ASCII 标记，中文可以跟在后面。

## 5. 资源与生成物

- **`.blend` 是美术的唯一编辑入口。** 不要手改 `.glb`，也不要手改 `manifest.json`
  （由 `art/export/export-blender-scenes.py` 生成）。
- `.import` 文件（如 `guyao.glb.import`）**要提交**，它记录了导入参数；`.godot/` 不要提交。
- 新增图片/音频后跑一次 `scripts\godot-import.ps1`，否则运行时 `load()` 会失败。
- 大文件策略：先本地提交，等要推远端时再决定是否接 git-lfs（已装 3.7.1）。
  目前最大的是 22 MB 的 WAV，还没到非用 LFS 不可的程度。

## 6. 提交

- 一个提交做一件事；提交信息用中文，首行 ≤50 字，说清"改了什么/为什么"。
- 不要提交：`.local/`、`game/.godot/`、`legacy/`、`export/`、任何 `*.log`、临时导出目录。
- 提交前跑一次 `scripts\check.ps1`（至少 `-SkipImport`）。
- 分支：`main` 保持可跑；功能分支 `feat/<模块>`、修问题 `fix/<一句话>`。

## 7. 性能预算（S1 之后逐步收紧）

| 项目 | 预算 | 当前 |
| --- | --- | --- |
| 单站 draw call | ≤ 40 | 26–32（等于 glTF 的 batches 数） |
| 单站三角面 | ≤ 60k | 25.4k–46.5k（优化前 47.5k–93.1k） |
| 单站 GLB 体积 | ≤ 3 MB | 1.30–2.54 MB |
| 工作台三角面 | ≤ 8k | 2.0k–6.3k |
| 包体 | ≤ 800 MB | 资产 22.5 MB + 工程 |
| 场景切换 | ≤ 5 s | 未测 |
| 目标帧率 | 1080p / 60 fps，Intel UHD 620 集显 | 未测 |

超出预算时优先合并材质（减少 batches），而不是删模型：现在的模型是 0 贴图纯色材质，
合并成本低；以后加贴图要重新评估。
